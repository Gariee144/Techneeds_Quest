# TechNeeds Quest

**Reimagathon | InnoVortex 4.0 | TechNeeds IGDTUW**

TechNeeds Quest reimagines the TechNeeds mentorship platform as a gamified learning journey. Mentees earn XP, levels, streaks and badges, compete on a live leaderboard, and get an AI-generated profile page.

This repository contains the **working frontend prototype**: a single `index.html` file with no installation needed.

## Run it

Double-click `index.html` to open it in your browser.

## Features

**Admin panel:** create mentorship programs, onboard mentors, generate secure mentor logins.

**Mentor panel:** add mentees with an auto-generated enrollment number and password, publish Videos, Quizzes and Projects with deadlines and maximum scores, view mentee profiles.

**Mentee panel:** secure login, learning dashboard with deadline countdowns, XP and levels, streaks, completion scoring, and a real-time leaderboard.

**AI-generated profile page:** generated avatar, skill badges, performance summary, skill levels and personalized learning recommendations.

## Prototype notes

- Data lives in the browser's memory, so it resets on refresh.
- The AI summary and recommendations are generated by rules from the live data. In the full version, the backend will send the user's stats to an LLM API.

## Planned full version

- Frontend: React, Tailwind CSS, Framer Motion, Recharts
- Backend: Node.js, Express and MongoDB (extending the provided TechNeeds backend)
- AI: LLM API called securely from the backend
- Deployment: Render
